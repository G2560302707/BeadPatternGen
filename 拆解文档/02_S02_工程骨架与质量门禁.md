# S02 · 工程骨架与质量门禁

> **所属** 一期 · 立项 ｜ **主导** Cursor ｜ **工期** 2–3 天 ｜ **前置** S01 ｜ **原文** 原文 P1

> 拆解版 v1.0（基于技术规格 v1.1 修正版）

## 本阶段目标

把「能跑质量门禁」这件事变成常态。后面每个阶段的验收都靠这套命令，它必须先绿、必须可信。

## 产出物

- React + TS + Vite + pnpm 工程
- tsconfig（strict）
- `ESLint / Prettier / Vitest 配置`
- `src/{app,components,features,core,workers,render,storage,export,test}`
- `docs/IMPLEMENTATION_STATUS.md`

## 验收门禁

```bash
pnpm install
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## 提示词（先粘贴全局约束，再粘贴本段）

````text
【本阶段】S02 · 工程骨架与质量门禁
（原文对应：原文 P1 ｜ 参考工期：2–3 天 ｜ 前置：S01）

【只做本阶段】完成本轮后立即停止。不要顺手实现下一阶段，不要实现任何逐颗人工编辑功能
（画笔 / 橡皮 / 吸管 / 填充 / 颜色替换 / 撤销重做 / 区域编辑 / 编辑自动保存）——那属于二期，
未经我逐字说「现在授权开始二期」不得触碰。

【开工前】
1. 阅读 docs/TECHNICAL_SPEC.md 与 docs/IMPLEMENTATION_STATUS.md，缺失就说明。
2. 检查仓库真实现状，列出「准备新增 / 修改的文件清单 + 方案 + 风险 + 验收方式」，再动手。
3. 与文档冲突时先停下指出，不要擅自扩大范围。

【本轮任务】
1) 工程初始化
   - React + TypeScript + Vite + pnpm；提交 pnpm-lock.yaml。
   - tsconfig 打开 strict、noUncheckedIndexedAccess、noImplicitOverride、exactOptionalPropertyTypes。
   - ESLint + Prettier + Vitest（jsdom 环境按需）。

2) 目录骨架（严格按此命名，命名本身是范围约束）
   src/app、src/components、src/features/{image-import,image-crop,generation-settings,
   pattern-preview,palette-panel,quality-report,export}、src/core、src/workers、src/render、
   src/storage、src/export、src/state、src/test。
   - 注意：是 pattern-preview，不是 pattern-editor。这个命名就是一期边界，不许改。

3) 页面空壳
   - 三栏工作区骨架：左侧参数面板 / 中央画布区 / 右侧颜色面板 + 底部状态栏 + 顶部导航。
   - 统一的加载态、空状态、错误提示组件（错误必须能被用户看到并重试，不许 alert）。
   - 骨架阶段所有面板可以是空态占位，但每个按钮要么有真实行为，要么不渲染。禁止渲染死按钮。

4) 最小类型与纯函数占位
   - 只建立 ImageMode / DitheringMode / BeadColor / BeadPattern 的类型骨架，
     以及 validatePattern() / computeStats() 的签名与「未实现」显式抛错（抛出带 code 的错误，不许返回假数据）。
   - 本阶段不实现任何图像算法。

5) package scripts：dev / build / lint / typecheck / test / test:e2e（e2e 可先空跑占位）。

【验收门禁】以下命令必须真实执行，并粘贴原始输出（跑不了的标「未运行」+ 原因）：
pnpm install
pnpm lint
pnpm typecheck
pnpm test
pnpm build

【交付报告】
1. 改动文件清单（新增 / 修改，一行一个，各附一句话作用）
2. 每条命令的原始输出（通过 / 失败；失败贴报错原文）
3. 未完成项与原因（没有写「无」）
4. 已知风险与我需要决策的点
5. 更新 docs/IMPLEMENTATION_STATUS.md
````

## 风险提示

最容易在这里埋下「死按钮」和「假数据占位」。占位一律用显式报错，不要用看起来像真的样例数据。
