# S12 分页切片几何：正确性证明

本文证明 `computePages` 满足 T1–T4。证明只使用整数与基本的 ceiling 性质，不依赖示例或测试。

## 0. 记号与输出定义

设：

- `W = width`，`H = height`（正安全整数）；
- `M = maxColsPerPage`，`N = maxRowsPerPage`（正安全整数）；
- `o = overlap`，取自 `0..4` 的安全整数，并满足 `o < M`、`o < N`；
- 横向步长 `sx = M - o`，纵向步长 `sy = N - o`。由 `o < M,N` 得 `sx, sy >= 1`。

定义横向页数：

```text
C = max(1, ceil((W - o) / sx))
```

纵向页数同理：

```text
R = max(1, ceil((H - o) / sy))
```

对 `i = 0..C-1`、`j = 0..R-1` 定义：

```text
x_i = i * sx                         y_j = j * sy
cols_i = min(M, W - x_i)             rows_j = min(N, H - y_j)
x 方向右重叠 right_i = 0 (i = C-1)   right_i = x_i + cols_i - x_{i+1} (i < C-1)
y 方向下重叠 bottom_j = 0 (j = R-1)  bottom_j = y_j + rows_j - y_{j+1} (j < R-1)
```

页矩阵按行优先编号：

```text
page(i, j) = j * C + i + 1
row = j, col = i
```

`PageSlice` 的其余字段即为 `x0 = x_i`、`y0 = y_j`、`cols = cols_i`、`rows = rows_j`。
每个页行固定有 `C` 页，每个页列固定有 `R` 页，因此共 `C * R` 页。

### 核心区的定义

把每页**减去右、下两侧与后一页重叠的部分**，得到该页的核心区：

```text
core_i     = [x_i, x_i + cols_i - right_i - 1]
core_j     = [y_j, y_j + rows_j - bottom_j - 1]
K(i, j)    = core_i × core_j
```

核心区是「此格由哪一页负责」的所有权划分，不是该页打印出来的全部区域。页与页打印区域仍然按 `o` 重叠。

---

## 1. 基础引理

**引理 L1（起点与裁剪）。** 对所有 `i`，`0 <= x_i < W`；并且：

1. 若 `W <= M`，则 `C = 1`，`x_0 = 0`，`cols_0 = W`；
2. 若 `W > M`，则 `C >= 2`，且对所有 `i < C - 1`，`cols_i = M`；
3. 最后一页 `cols_{C-1} = W - x_{C-1}`；若 `C >= 2`，还满足 `o < cols_{C-1} <= M`；
4. 横向起点严格递增，`x_{C-1} + cols_{C-1} = W`。

**证明。**

- 若 `W <= M`，则 `(W - o)/(M - o) <= 1`，故 `C = max(1, ceil(...)) = 1`。此时 `x_0 = 0 < W`，`cols_0 = min(M, W) = W`。
- 若 `W > M`，则 `W - o > M - o = sx`，故 `(W - o)/sx > 1`，从而 `ceil(...) >= 2`，`C >= 2`。
- 对 `C > 1`，由 `C = ceil((W - o)/sx)` 得

  ```text
  (C - 1) * sx < W - o                         (1)
  (C - 1) * sx >= (W - o) - sx = W - M         (2)
  ```

  由 `(1)` 得 `x_{C-1} < W - o < W`，因此 `x_{C-1}` 不越界；由 `(2)` 得 `x_{C-1} >= W - M`，两边乘 `-1` 后加 `W` 得

  ```text
  cols_{C-1} = min(M, W - x_{C-1}) = W - x_{C-1} <= M
  ```

  并且 `W - x_{C-1} > o`，所以 `o < cols_{C-1} <= M`。

- 对任意 `i < C - 1`，有 `x_{i+1} <= x_{C-1}`，于是

  ```text
  x_i + M = x_{i+1} + o <= x_{C-1} + o < W
  ```

  故 `cols_i = min(M, W - x_i) = M`。所有起点按 `sx >= 1` 严格递增，最后一页显然满足 `x_{C-1} + cols_{C-1} = W`。

纵轴将 `W,M,x_i,cols_i,sx,C` 分别替换为 `H,N,y_j,rows_j,sy,R` 后，L1 逐字成立。

---

## 2. T2：重叠精确

**定理 T2（水平重叠）。** 当 `C = 1` 时没有水平相邻页，`overlapRight = 0`。当 `C >= 2` 时，对每个 `i = 0..C-2`，第 `i` 页与第 `i+1` 页实际共享的列数等于

```text
min(o, 下一页可用列数) = o
```

且该值等于 `overlapRight` 字段。

**证明。**

由 L1，所有非末页 `cols_i = M`。因此对 `i < C - 1`：

```text
x_i + cols_i - x_{i+1} = x_i + M - (x_i + sx) = M - sx = o
```

末页 `cols_{C-1} > o`，非末页 `cols_i = M > o`，所以每一对相邻页中，后一页实际有足够的列参与这 `o` 列重叠，`min(o, 后一页可用列数) = o`。字段定义正是 `x_i + cols_i - x_{i+1}`，故字段与实际共享列数一致。

最后一列没有右邻页，按输出契约 `overlapRight = 0`。

把「列」换成「行」、`x` 换成 `y`、`cols` 换成 `rows`，即得纵向版本：每个垂直相邻对共享恰好 `o` 行，最后一行的 `overlapBottom = 0`。`o = 0` 时上述推导给出共享 `0` 格，T2 自然退化为不重叠。

## 3. T1：完整性（不重不漏）

**定理 T1。** 对图纸中的任意格 `(x, y)`，`0 <= x < W`、`0 <= y < H`，存在唯一一页 `p`，使 `(x, y)` 落在 `p` 的核心区 `K(p)` 内。因此全部 `W * H` 个格被各页的核心区恰好覆盖一次。

**证明。**

先证一维。当 `C = 1` 时，唯一核心区是 `[0, W - 1]`，结论直接成立。以下设 `C >= 2`。

由 L1，对 `i < C - 1`：

```text
core_i = [x_i, x_i + M - o - 1] = [x_i, x_i + sx - 1] = [x_i, x_{i+1} - 1]
```

而末页：

```text
core_{C-1} = [x_{C-1}, x_{C-1} + (W - x_{C-1}) - 1] = [x_{C-1}, W - 1]
```

这些区间依次首尾相接：第 `i` 个区间的右端是 `x_{i+1} - 1`，下一个区间的左端是 `x_{i+1}`；没有空隙，也没有公共整数点。故它们的并集为

```text
[0, x_1 - 1] ∪ [x_1, x_2 - 1] ∪ ... ∪ [x_{C-1}, W - 1] = [0, W - 1]
```

并且各核心区宽度之和为

```text
(C - 1) * sx + (W - x_{C-1}) = (C - 1) * sx + W - (C - 1) * sx = W
```

纵轴用同样推导得到核心区 `core_j` 划分 `[0, H - 1]`。二维核心区是 `core_i × core_j`；笛卡尔积保持划分性质：每个 `(x, y)` 由唯一的 `(i, j)` 组合覆盖。因此每格在全部页核心区中的覆盖计数恰好为 `1`，满足「至少一次」且「不重不漏」。

注意：核心区不覆盖右 / 下重叠带，但那些格会作为下一列 / 下一行页核心区的左 / 上部分被覆盖；所以删除重叠带不会造成漏格，反而避免重复归属。

## 4. T3：边界安全

**定理 T3。** 对每一页，`x0 >= 0`、`y0 >= 0`、`cols >= 1`、`rows >= 1`，并且

```text
x0 + cols <= W
y0 + rows <= H
```

不存在越界切片，也不存在为了凑满页容量而补出的空白格。

**证明。**

`x0 = x_i >= 0`，`y0 = y_j >= 0`。由 L1 有 `x_i < W`，所以 `W - x_i >= 1`，进而

```text
cols_i = min(M, W - x_i) >= 1
x_i + cols_i = x_i + min(M, W - x_i) <= x_i + (W - x_i) = W
```

纵轴同理：`rows_j >= 1` 且 `y_j + rows_j <= H`。页面尺寸直接取剩余格数与容量的较小值，最后一页的 `cols/rows` 就是真实剩余量，没有任何向上取整或补格操作。

## 5. T4：页数最少

**定理 T4。** 在满足 T1–T3 的矩形页矩阵拼版中，页数下界为

```text
C * R
其中 C = max(1, ceil((W - o) / (M - o)))
     R = max(1, ceil((H - o) / (N - o)))
```

本实现恰好输出 `C * R` 页，因此页数最少。

**证明（横向下界）。**

考虑任意一个页行中的页，按 `x0` 升序排列为 `p_1, ..., p_n`。由于所有格都必须被覆盖，`p_1.x0 = 0`（否则 `x = 0` 的格无人覆盖，违反 T1）。T2 要求每一对水平相邻页恰好共享 `o` 列，所以

```text
p_{t+1}.x0 = p_t.x0 + p_t.cols - o <= p_t.x0 + (M - o) = p_t.x0 + sx
```

归纳得

```text
p_n.x0 <= (n - 1) * sx
```

再由 T3 / 页容量得 `p_n.cols <= M`，故最右端最多到

```text
p_n.x0 + p_n.cols <= (n - 1) * sx + M
```

要覆盖 `W` 列，必须 `(n - 1) * sx + M >= W`，即

```text
n >= 1 + ceil((W - M) / sx)     (W > M)
```

当 `W <= M` 时，至少需要 1 页，且 1 页足够。该下界与第 0 节的 `C` 等价；若用统一写法可直接写成 `n >= ceil((W - o) / sx)`（`W <= M` 时右端为 1 或更小，取至少 1 页即得 `C`）。因此每个页行至少 `C` 页。

纵轴对称地推出每个页列至少 `R` 页。矩形矩阵若少于 `R` 个页行，则纵向无法覆盖 `H`；若少于 `C` 个页列，则横向无法覆盖 `W`。所以矩阵至少有 `R` 行、`C` 列，总页数至少 `R * C`。实现按 `j = 0..R-1`、`i = 0..C-1` 构造，页数恰为 `R * C`，达到下界，故最少。

> 末页不允许「向前对齐到 `W - M`」。那样虽然能让末页满宽，却会使末页与前一页共享超过 `o` 列（例如 `W=200, M=40, o=2` 时共享 32 列），直接违反 T2。T2 与 T4 共同迫使最后一页从 `(C-1)*sx` 开始，接受其较小的剩余宽度。

## 6. 边界结论

下表中的「单页」均指非法输入已先被拒绝后的合法请求。校验优先级固定为：尺寸合法性 → `overlap` 是安全整数 → `overlap` 小于页容量 → `overlap` 位于 0–4。容量校验先于上界范围校验，因此在 `o >= M` 或 `o >= N` 时，即使 `o` 同时大于 4，也返回任务规定的 `E_OVERLAP_TOO_LARGE`。

| 条件                           | 结论                                                                                                                                     | 依据                              |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| `W < M`                        | 横向 `C = 1`；该列唯一页 `x0 = 0`，`cols = W`，`overlapRight = 0`。若同时 `H <= N`，总页数为 1；若 `H > N`，只会在纵向继续分页。         | L1、T2                            |
| `o >= M` 或 `o >= N`           | 在任何切片计算前抛出 `PaginationError`，`code = "E_OVERLAP_TOO_LARGE"`，message 以该码开头。                                             | 输入校验                          |
| `W = 1, H = 1, M = 1`          | 唯一合法的 `o` 是 `0`；输出单页 `(x0,y0)=(0,0)`、`cols=rows=1`、两重叠字段均为 0。若 `o >= 1`，则 `o >= M`，`E_OVERLAP_TOO_LARGE` 优先。 | L1、输入校验                      |
| `o = 0`                        | `sx = M`、`sy = N`；相邻页起点相差整页容量，共享 0 列 / 0 行；`overlapRight = overlapBottom = 0`。T2 的 `min(o, available) = 0`。        | T2                                |
| `o` 缺省（`undefined`）        | 按默认值 `2` 处理；`2 >= M` 或 `2 >= N` 时仍先抛 `E_OVERLAP_TOO_LARGE`。                                                                 | 常量 `DEFAULT_OVERLAP`            |
| `o` 非整数 / 负数 / 大于 4     | 抛 `PaginationError`，`code = "E_INVALID_OVERLAP"`。                                                                                     | 常量 `MIN_OVERLAP`、`MAX_OVERLAP` |
| `W,H,M,N` 非正整数或非安全整数 | 抛 `PaginationError`，`code = "E_INVALID_DIMENSION"`。                                                                                   | 输入校验                          |

## 7. 确定性说明

1. 全部几何量由整数 `+ - *` 与整数除法上取整得到；代码中不存在浮点累加，也不存在容差比较。`countPagesOnAxis` 的 `Math.ceil` 只作用于整数比值，结果是精确整数。
2. 遍历顺序固定为外层 `row` 升序、内层 `col` 升序；`page = row * C + col + 1`，没有依赖 `Map` / `Set` / 对象键顺序。
3. 不读取 `Date`、`Math.random`、环境变量或外部状态；相同请求必得深相等的输出。
4. 阈值集中为 `DEFAULT_OVERLAP = 2`（技术规格 §8.2）、`MIN_OVERLAP = 0`（S12 边界契约）、`MAX_OVERLAP = 4`（技术规格 §8.2）。不存在散落的魔法数。
5. 实现文件没有运行时 `import`；仅有的 `import type` 在编译后擦除，零第三方依赖。
