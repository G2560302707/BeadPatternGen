# 算法落地拆解（S01 · 只拆解，不实现）

对应规格 **4.1 总流程**（v1.1 原文，从 `拼豆图纸生成器_技术实施规格_v1.1_修正版.docx` 抽出，因 `docs/TECHNICAL_SPEC.md` 尚不存在）。

规格原文（4.1）：

> RGBA 源图 → EXIF 方向纠正与格式校验 → 裁剪 / 透明度策略 / 颜色管理 → 依据目标网格尺寸进行高质量缩放 → 计算每格代表色（默认面积平均；可选线性光平均实验）→ 按模式分析边缘、区域和重要结构 → 映射到有限的目标色卡 → 颜色量化与可选抖动 → 局部结构优化与孤立豆子诊断 → 统计、校验、生成 Pattern。
>
> 禁止：任何网络调用或大模型参与颜色映射。第一版只允许本地启发式。

下列每一步写清类型、失败、能否纯函数。标注决定后续分工：能在 Node 用固定向量测的 → 国产模型阶段（S04/S05/S07/S08/S09/S12）；必须碰浏览器文件/Canvas 的 → Cursor 阶段（S06/S10/S11/S13/S14）。

类型名按规格第 5 章预留，本阶段不实现。

---

### 1. `decodeSourceImage`

- **输入：** 用户文件字节（`Uint8Array`）+ 声明 MIME / 文件名。
- **输出：** `{ rgba: Uint8ClampedArray, width: number, height: number, decodedMime: "image/jpeg" \| "image/png" \| "image/webp" }`（未旋转）。
- **失败：** 扩展名与解码结果不符；超文件大小 / 超宽高 / 超总像素；损坏文件；不支持格式。
- **纯函数化：** 解码本身无随机性，但**依赖浏览器或解码库**，不能当零依赖纯 TS。
- **测试位置：** 必须真实文件 + 解码器 → **Cursor / 浏览器（S06）**。

### 2. `applyExifOrientation`

- **输入：** 解码像素 + EXIF 方向标签（1–8）。
- **输出：** 纠正后的 `rgba, width, height`。
- **失败：** 方向值非法则拒绝，不静默当 1。
- **纯函数化：** 像素重排可以是纯函数；**读 EXIF 依赖解码侧**。
- **测试位置：** 像素重排矩阵可 Node 测；读 JPEG EXIF → **Cursor（S06）**。

### 3. `validateImageLimits`

- **输入：** 宽、高、字节数、配置上限。
- **输出：** `void` 或抛错。
- **失败：** 超限。
- **纯函数化：** **是。**
- **测试位置：** **Node（可并入 S06 测试，逻辑放 core）**。

### 4. `cropRgba`

- **输入：** RGBA 缓冲、源宽高、裁剪框 `{ x, y, width, height }`（像素，整数）。
- **输出：** 裁剪后 RGBA 与新宽高。
- **失败：** 框越界、宽高 ≤ 0、非整数。
- **纯函数化：** **是**（给定已解码缓冲）。
- **测试位置：** **Node（S06）**。

### 5. `applyTransparencyPolicy`

- **输入：** RGBA；`transparentPolicy: "empty" \| "background"`；可选 `backgroundHex`（必须是当前色卡合法色或明确的背景填充色——背景填充若只用于采样前合成，最终空格仍由后续步骤决定）。
- **输出：** 每像素 alpha 分类后的 RGB，以及「该像素是否视为透明」掩码。
- **失败：** `background` 模式缺少合法 `backgroundHex`；静默丢 alpha（规格禁止）。
- **纯函数化：** **是。**
- **测试位置：** **Node（S06）**。

### 6. `colorManageToSrgb`（第一版可为空操作并文档化假设）

- **输入：** RGB；可选嵌入 ICC。
- **输出：** 当作 sRGB 显示的 RGB。
- **失败：** 第一版不解析 ICC 时必须**声明「按 sRGB 解释」**，不得假装做了 CMS。
- **纯函数化：** 有配置则可。
- **测试位置：** 第一版跳过 CMS → 文档约束；若实现矩阵转换 → **Node（S04）**。

### 7. `resizeToGridFootprint`

- **输入：** RGBA、源宽高、目标豆子网格 `gridW, gridH`（格子数，不是显示像素）。
- **输出：** 仍为栅格图，但其宽高与后续「每格一块」对齐的中间表示；或直接进入逐步采样。
- **失败：** `gridW/gridH` 非正整数或超过性能上限。
- **纯函数化：** 过滤器确定后 **是**；实现可用纯 TS 或依赖 Canvas `drawImage`。
- **测试位置：** 纯 TS 采样则 **Node（S06）**；若用 Canvas 缩放则 **浏览器**，且必须有对照测试防实现漂移。

### 8. `sampleCellRepresentativeColor`（规格默认：面积平均）

- **输入：** 源图 RGBA、每格对应的源矩形、可选 `averageSpace: "srgb" \| "linear-srgb"`。
- **输出：** `RGBColor[]` 长度 `gridW * gridH`，以及平行的 `alphaMask`（整格视为空的布尔）。
- **失败：** 矩形为空。透明格按策略标空，不得用 `(0,0,0)` 冒充黑豆。
- **纯函数化：** **是。**
- **测试位置：** **Node（S06）**。线性光平均标为实验开关。

### 9. `analyzeStructureForMode`

- **输入：** 每格代表色；`mode: "photo" \| "anime" \| "logo" \| "landscape"`。
- **输出：** 结构权重图（边缘强度、区域标签、重要性掩码）。第一版为启发式，**不宣称人脸语义**。
- **失败：** 未知 mode。
- **纯函数化：** **是**（禁止随机）。
- **测试位置：** **Node（S09）**。

### 10. `selectActivePalette`

- **输入：** 完整 `PaletteDefinition`；`maxColors`。
- **输出：** 参与匹配的色卡子集（仍全部是真实色号）。
- **失败：** palette 校验失败（重复色号、非法 HEX）；`maxColors < 1`。若真实色数 `< maxColors`，使用全部真实色，不得发明合成色。
- **纯函数化：** **是。**
- **测试位置：** **Node（S05）**。

### 11. `matchCellsToPalette`（量化，无抖动）

- **输入：** 每格 RGB（或 Lab/Oklab）、`PaletteIndex`、`ColorMetric`（基线 CIEDE2000，候选 Oklab）。
- **输出：** `Int16Array` cells（`-1` 空格，否则为 palette 下标）。
- **失败：** 最近邻返回越界下标（测试必须抓住）。
- **纯函数化：** **是。**
- **测试位置：** **Node（S04 色空间 + S05 最近邻）**。

### 12. `ditherFloydSteinberg`（可选）

- **输入：** 每格线性/sRGB 色、色卡、cells 初值、mode 允许的抖动开关。
- **输出：** 新的 cells。
- **失败：** anime/logo 在规格下强制 `none`，传入 FS 应拒绝或被策略层拦截。
- **纯函数化：** **是**，若写死：左→右、上→下；边界误差丢弃。
- **测试位置：** **Node（S07）**。

### 13. `optimizeLocalStructure`

- **输入：** cells、palette、结构权重、可配置目标函数权重。
- **输出：** 新 cells；每个格子的候选色必须仍是合法色卡下标。
- **失败：** 优化后出现合成色或越界下标。
- **纯函数化：** **是**（确定性邻域搜索）。
- **测试位置：** **Node（S09）**。

### 14. `diagnoseQuality`

- **输入：** cells、grid 尺寸、源分辨率、每格色差。
- **输出：** 诊断项列表（细线风险、孤立豆=4-邻域无同色、连通分量 ≤ 2 碎片、高色差格）。**不输出假精确总分百分比。**
- **失败：** 无；空图返回空列表。
- **纯函数化：** **是。**
- **测试位置：** **Node（S08）**。

### 15. `computeColorStats`

- **输入：** cells、palette。
- **输出：** 每色 count / percentage；`sum(counts) === 非空格数`。
- **失败：** 不变量打破则抛错，禁止显示假统计。
- **纯函数化：** **是。**
- **测试位置：** **Node（S03）**。

### 16. `assembleBeadPattern`

- **输入：** cells、palette 元数据、settings、source 尺寸与裁剪。
- **输出：** `BeadPattern`（`schemaVersion: "1.0"`）。
- **失败：** `cells.length !== width * height`；非法索引。
- **纯函数化：** **是。**
- **测试位置：** **Node（S03）**。

### 17. Worker 调度（非算法，但是 4.1 落地必需）

- **输入：** 任务 ID、可转移图像缓冲、参数。
- **输出：** 进度事件 + 最终 Pattern。
- **失败：** 取消；新任务 ID 必须丢弃旧结果。
- **纯函数化：** 否（并发与浏览器线程）。
- **测试位置：** **Cursor（S10）**。

### 18. 预览 / 导出（4.1 之后，规格 8 章）

- 渲染与 PDF 切片几何：几何计算可纯函数（S12）；画 Canvas / 写 PDF 文件依赖浏览器（S11/S13）。
- 禁止在导出时重新量化颜色。
