# 算法升级 1.2：主体识别残缺与小尺寸失真修复

> 日期：2026-10-25 · 分割算法版本 `SEGMENTATION_ALGORITHM_VERSION = "1.2"`
> 验证：单测 513/513 绿、E2E 14/14 绿、`pnpm quality:run` 全图集目检（`测试输出/`）
> 对照标准：`算法优化库/` 中 52×52/18 色、78×78/22 色、104×104/13 色的优秀作品

## 一、问题归因（基线实测）

| 症状 | 根因 |
| --- | --- |
| 主体整片半透明、发白、采样后变空格 | 蒙版数值是模型置信度（前景内部常仅 60–150），C3 直接当 alpha 用，`alpha<128` 判空 |
| 棕发贴棕背景等低对比区域被切掉 | 单一 Otsu 阈值把弱响应带里的成片主体判成背景 |
| 线稿白底内部镂空（只剩描边） | DIS 系模型对平涂内部输出 ≈0，填充上限 16px 盖不住几十万像素的洞 |
| 小图斑噪（孤立豆 100–430、碎片 124–520） | 面积采样散布 + 逐格独立最近邻匹配 |
| 描边断裂、五官发灰 | sRGB 直接平均稀释暗线；眼睛等小而远的颜色簇排不进 maxColors |

## 二、分割侧改动

1. **默认模型 → `isnet-anime`**（manifest `defaultModelId`；输入名 `img`，1024²）。
   全图集实测置信度持平或更好：线稿白底内部、粉色开衫等低对比区域不再被切。
   照片/宠物场景可在抠图页手动选回 `isnet-general-use`。
2. **滞后阈值（hysteresis）**：`> threshold` 的强种子向外 4 邻域扩散，
   把 `> threshold × 0.55` 且与主体连通的弱响应像素并入前景（Canny 思想）。
3. **清理面积按图像比例**：去噪 `0.02%`、填孔 `0.3%`（`scaledMaskCleanupAreas`，
   绝对下限保持旧默认），百万像素照片上不再"没清"。
4. **巨型封闭孔洞救援**：封闭背景块面积 > 全图 12% 且包围壳前景 < 洞 × 0.6
   （线稿薄壳特征）时整洞填回；人像叉腰三角缝、相框中空等合法空洞不触发。
5. **不透明度归一化**（收尾步骤）：前景 `[T,255] → [129,255]`、背景 `[0,T] → [0,127]`，
   以空格判定线 128 为对称中心——覆盖率 ≤50% 的格子仍是空格，主体内部从此实心。
6. **二次推理合并带阈值谐波**（`mergeRefinedMask`）：裁剪区按各自 Otsu 锚定
   分段线性映射到全图尺度再逐像素取 max，修掉"越精修越残缺"。

## 三、采样与量化侧改动

1. **线性光面积平均**（`sampleToGrid` 1.1 语义）：sRGB EOTF 往返，消除 sRGB
   直接平均的暗色稀释（50% 黑 + 50% 白 = 187 而不是 188 的错误暗化）。
2. **细暗线三档判据**（对齐优秀作品的描边表现）：
   - 轮廓线（细长且贴透明区）：整格或 0.9 取线色——剪影描边不断裂；
   - 深色主块（占比 ≥35%、亮度 ≤100、对比 ≥80）：向深色收敛——眼睛虹膜不再发灰；
   - 内部细线：`min(0.5, ΔL/160 × 占比/0.15)` 温和染色——小图纸上五官线
     淡化为浅阴影而不是黑条纹；柔和阴影不偏置。
3. **k-means 选色**（`selectPaletteSubset` 1.2）：最远点确定性初始化 + Lloyd ≤32 轮，
   中心映射真实色卡色后按簇权重去重；k=1 跳过 Lloyd（保留"覆盖最大者"契约）。
   小而远的颜色簇（眼睛、腮红、小饰物）从此能进 maxColors。
4. **S09b 色块平整化**（`flattenRegions`，接在抖动后、S09 修复前）：
   - 多数投票：4 邻域 ≥3 同色且 ΔE ≤ 1.4 × 模式合并阈值 → 改色；
   - 碎片合并：≤2 格连通碎片并入色距最近的相邻分量（ΔE ≤ 1.5 × 阈值）。
   直线边缘（2/4 同色）与真细节（ΔE 大）天然受保护。

## 五、已知边界

- 背景发光贴纸贴在花哨深色背景上时（如 `0df8b7cb`），isnet-anime 可能把部分
  带星星的背景一并判为主体——模型语义层面的选择，可用画笔工具擦除。
- 16 色在 52 格下，2 格以内的极小点缀（如张开的嘴）可能被并入邻近色；
  追求参考作品级的五官表现可把颜色数提到 24–32。
