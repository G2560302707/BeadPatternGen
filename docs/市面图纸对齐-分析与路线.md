# 与市面优秀图纸对齐：实证分析与路线

> 2026-10-25 · 基于参考图集（261 张市面图纸/成品，见 `参考图集/SOURCES.md`）
> 分析工具：`scripts/analyze-reference.mjs`（网格反提取 + probe 模式），原始数据 `参考图集/分析/reference-stats.json`

## 一、结论：能不能"训练"？

**端到端神经网络训练（原图→图纸生成模型）不可行，也不必要：**

1. **数据量差 2-3 个数量级**。图像翻译类模型（pix2pix 类）需要数千到数万张严格配对的（原图，图纸）训练对。参考图集中严格配对的样本不足 40 张，且多为同框拍摄（非像素级对齐）。
2. **缺监督信号**。反提取只能从人工图纸上得到"图纸本身"，拿不到"作图者看到的原图"，无法构成 (输入, 期望输出) 对。
3. **架构不匹配**。本项目是纯前端应用（浏览器端 ONNX 推理只用于主体分割），引入生成模型意味着数百 MB 模型与训练管线，收益远低于成本。
4. **任务本质是规则问题**。市面图纸的生成过程（采样→减色→平整→标注）是可解释的确定性流程，市面作品的"好看"来自**参数与先验**，不来自神经网络。

**可行且已验证的路线：数据驱动对齐**——把市面图纸反提取成统计先验，修正我们管线的参数与规则，用 `quality:run` 建立回归门禁。下面是实证。

市面共性（**先验**）：

- **用色数 5-15，典型 5-10 色**。越卡通越少（5-7），写实/细节多才到 12-15。
- **网格 24-120 豆，典型 33-67**；每格印色号 + 行列坐标轴 + 底部图例（色块/色号/豆数）。
- **大色块主导**：主体色占 40-50%（如 H2×637/1439），1-2 颗的孤立点缀豆每图仅 0-3 处（眼睛高光等**有意设计**）。
- **黑白灰是骨架**：H1 白、H6-H9 灰阶、H7 黑，M12/M15 深灰棕承担描边与阴影；高频色高度集中在 221 色的一小撮。
- **写真实图靠多级灰阶渐变**（相邻灰号 H1→H4→H5→H8），不是靠噪点抖动。

## 四、对齐行动清单（按性价比排序）

1. **maxColors 按尺寸自适应**（改动最小、收益最大）：不再固定 16，按长边查表——≤33 豆给 8-10 色，34-60 豆给 10-12 色，>60 豆给 12-15 色；写实模式可上浮 2 色。位置：`GenerateControls` 默认值 + `getModeProfile` 或新档位表。
2. **碎片治理目标化**：把「孤立豆率 <5%、同色碎片 <3%」写进 `quality:run` 作为门禁指标（现在只有 isolated/fragments 计数没有占比基准）；调 `flattenRegions` 的 colorMergeThreshold 与 `refineLocally` 的孤立豆修复强度，直到 21 张测试图过门禁。注意保留眼睛高光类"有意的 1-2 豆"——判据：被深色描边包围且 ΔE 周边大。
3. **色号频率先验**：从参考图集统计高频色号（H1/H2/H5/H6/H7/M12/M15/C24 量级），做成 `palette` 的先验权重 fixture；`selectPaletteSubset` 的聚类中心→色卡映射在 ΔE 接近时（如 <2）偏向高频色。规则级改动，无训练。
4. **网格档位与默认值**：默认推荐档从 26 改到 33/52/67；分享图导出对齐 MARD 样式（每格色号+坐标轴+底部图例带豆数）——此项已在产品方向内，属导出层。
5. （可选）**写实多级灰阶**：anime/general 模式检测到大面积低饱和区域时，允许同一灰阶族取 2-3 个相邻色号（如 H4/H5/H8），替代抖动。

## 五、工具与数据资产

- `scripts/analyze-reference.mjs`：参考图纸反提取（全自动网格线检测 / `--probe` 方差谷探测两种模式），输出网格叠加与重建预览供目检。
- `参考图集/分析/reference-stats.json`：反提取原始统计。
- 人工读数表（本文第二节）是当前最可信的基准，已可直接驱动行动 1/3 的参数设计。
- 反提取的已知边界：图纸格内印刷的色号文字会污染小格（≤10px）采样，probe 模式用 9 点众数投票 + 共识度过滤缓解；拍照歪斜的图自动跳过。后续若需要更大样本，可对 152 张图纸批量跑 probe 后人工目检通过项。

## 六、后续验证闭环

每次改动后跑 `pnpm quality:run`，对比 summary.json 三个门禁：用色数落入市面区间（按尺寸查表）、孤立豆率 <5%、meanΔE 不高于现状基线（5.5）。三项全绿才算"更接近市面作品"。
