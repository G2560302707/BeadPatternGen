1. 项目目标与范围
1.1 产品目标
开发一个高质量拼豆图纸生成 Web 应用。用户上传图片，选择目标网格尺寸、拼豆品牌色卡、颜色上限和图像模式，程序生成逐格映射到真实拼豆颜色的图纸；用户可查看每色用量，导出高清图片、可打印 PDF 和可重新编辑的项目文件。一期仅提供只读预览；逐颗人工修正属于二期。

一期不实现人工编辑器；仅提供生成结果预览。画笔、橡皮、取色、填充、撤销/重做、颜色替换全部放入二期。
保存恢复：一期支持生成项目的本地保存/打开及 JSON 导入导出。
导出：PNG、分页 PDF、颜色清单 CSV、项目 JSON。
质量诊断：低分辨率细节提示、孤立豆子提示、色卡映射和计数校验。
1.4 一期明确不做的内容
不需要账号系统、云同步、会员、支付、社区和商城。不将大语言模型作为每次转换的必需依赖。不承诺任意照片都能完美还原；程序应解释网格分辨率和色卡限制。不在未审查许可证前复制第三方开源代码或色卡数据。
一期不做：
逐颗画笔绘制、橡皮擦、吸管、区域填充、手工颜色替换、选区复制粘贴、移动/镜像/旋转、编辑撤销重做、修改过程自动保存、局部重新生成、图层和编辑版本管理。
一期可以有：
上传、裁剪、生成参数、生成进度、原图与生成结果对照、质量诊断、颜色用量统计、生成结果保存/打开、PNG/PDF/JSON/CSV 导出。预览中的网格仅用于查看，不得出现会改变图纸数据的编辑交互。
二期目标：
新增独立的人工精修工作台，打开一期生成的 BeadPattern 后，允许逐颗修改并同步更新预览、统计、保存和导出。二期不得重写或破坏一期算法核心。

3.1 架构边界
UI 层：只处理交互和显示，不直接写量化、抖动算法。
core 层：纯 TypeScript，可在不启动 React 的情况下运行测试。
worker 层：调用 core API，负责任务调度、进度、取消。
storage 层：封装 IndexedDB，不允许组件直接操作数据库。
render 层：根据 Pattern 绘制，不自行计算或修改颜色矩阵。
export 层：读取最终 Pattern，生成 PNG、PDF、项目 JSON、CSV。
3.2 依赖管理要求
Cursor 应在实施前确认当前兼容版本，使用 pnpm 添加依赖并提交 lockfile。避免未经说明加入大型依赖。颜色空间/色差库、PDF 库、画布库需在 docs/DEPENDENCY_DECISIONS.md 记录版本、许可证、体积、替代方案和采用理由。
4. 算法设计与高还原度策略
4.1 总流程
RGBA 源图 → EXIF 方向纠正与格式校验 → 裁剪 / 透明度策略 / 颜色管理 → 依据目标网格尺寸进行高质量缩放 → 计算每格代表色（默认面积平均；可选线性光平均实验）→ 按模式分析边缘、区域和重要结构 → 映射到有限的目标色卡 → 颜色量化与可选抖动 → 局部结构优化与孤立豆子诊断 → 统计、校验、生成 Pattern。
禁止：任何网络调用或大模型参与颜色映射。第一版只允许本地启发式。
4.2 颜色空间与量化
实现可插拔的 ColorMetric 接口。第一基线采用 CIEDE2000；候选方案采用 Oklab 距离。不要预先断言某方案一定更好，必须在固定测试集、色卡、网格尺寸下做对比。色卡颜色先规范化为 sRGB，再转换到目标颜色空间并缓存。
interface ColorMetric { distance(a: LabColor, b: LabColor): number; }
interface PaletteIndex { nearest(color: RGBColor, candidates?: number[]): PaletteMatch; }
interface QuantizationOptions {
  metric: "ciede2000" | "oklab";
  maxColors: number;
  dithering: "none" | "floyd-steinberg";
  mode: "photo" | "anime" | "logo" | "landscape";
}
实现注意事项：
先进行图像采样，再匹配色卡；不要简单地对原图所有像素直接取最近色。
真实色卡必须来源可追溯，并记录品牌、系列、版本、色号、色名、HEX、来源和许可信息。P0/P1 必须锁定至少一套可用色卡并写入 fixtures。
最大颜色数是对输出色卡颜色数量的限制；不能将不存在于真实色卡的合成颜色作为最终豆子颜色。若真实色卡颜色数 < maxColors，则使用色卡全部颜色。
色差库和颜色空间转换需要单元测试，特别是黑白、灰色、极端 RGB 和已知测试向量。
4.3 网格采样
把目标图纸宽高当作豆子数量，而不是显示像素。每个输出格对应源图一个区域。默认实现：抗锯齿面积采样（sRGB 空间按面积加权平均）。高质量实验模式可比较线性光空间求平均的视觉差异。透明像素默认策略为 "empty"（空格，不拼豆子）；可配置为指定背景色。不可静默丢失透明信息。

4.5 局部优化
在基础量化之后，可对每个格子尝试邻近合法色卡颜色，评估局部目标函数是否改善。目标函数可包含色差、孤立点惩罚、重要边缘惩罚和颜色数量约束。所有启发式权重都应可配置、可测试，并通过基准图片验证；避免为了减少噪点而破坏眼睛、细线或 Logo 字母。
4.6 质量诊断
检测低于单豆尺寸的细线/文字，并提示增大图纸尺寸。
孤立豆定义：4-邻域内无同色格子的非空格。小型碎片：连通分量大小 ≤ 2 的区域。给出预览与数量，不自动删除。
展示实际使用色数、豆子总数、每色数量及可能的高色差区域（单格与目标色差超过阈值时标记）。
当色卡不完整或色号重复时，提示冲突并阻止生成不可信结果。
质量评分若无可靠定义，不要输出看似精确的百分比。先显示可解释的诊断项。
5. 图纸数据模型
5.1 TypeScript 数据类型
export type ImageMode = "photo" | "anime" | "logo" | "landscape";
export type DitheringMode = "none" | "floyd-steinberg";
export type ColorMetricName = "ciede2000" | "oklab";
export interface BeadColor {
  code: string; name: string; hex: string;
  manufacturer: string; series?: string;
}
export interface BeadPattern {
  schemaVersion: "1.0";
  id: string; title: string;
  width: number; height: number;
  // 内存：Int16Array；JSON 导出：普通 number[]（-1 = 空格）
  cells: Int16Array;
  palette: BeadColor[];
  mode: ImageMode;
  paletteId: string;
  paletteVersion: string;
  paletteHash?: string; // 推荐：色卡内容哈希，防止版本漂移
  settings: {
    maxColors: number;
    dithering: DitheringMode;
    colorMetric: ColorMetricName;
    transparentPolicy: "empty" | "background";
    backgroundHex?: string;
  };
  source: {
    originalWidth: number; originalHeight: number;
    aspectRatio: number;
    crop?: { x: number; y: number; width: number; height: number };
  };
  createdAt: string; updatedAt: string;
}
5.2 数据不变量
cells.length 必须严格等于 width * height。
每个格子只能是 -1 或有效 palette 索引（0 ≤ index < palette.length）。
每个 palette 色号在同一品牌/系列版本内必须去重。
统计总数 = 所有非空格数 = 各色数量之和。
保存和导出时必须保留 schemaVersion、paletteId、paletteVersion（推荐 paletteHash）。
导入 JSON 必须进行 schema 校验、尺寸上限校验和色卡引用校验。
JSON 编码规定（修正补充）：
序列化时将 Int16Array 转为普通 number[]；反序列化时再 new Int16Array(arr)。禁止依赖 JSON.stringify(Int16Array) 的默认行为。schemaVersion 用于未来迁移。
5.3 命令式编辑（仅二期）
二期编辑器中的画笔、橡皮、填充、替换颜色应通过独立命令或差异记录修改 Pattern。撤销/重做建议保存变更的索引、旧值和新值；填充等大操作可采用压缩后的批量差异。一期只定义兼容的数据模型，不实现这些编辑交互。

8. 导出规范
8.1 PNG
一个豆子格对应固定的输出单元尺寸。
可配置显示网格、坐标、色号、颜色图例和总数。
输出图像颜色必须来自图纸 palette，不得重新采样或进行额外的色彩量化。
大图导出需分块或离屏渲染，防止一次分配超大 Canvas 导致浏览器崩溃。
8.2 PDF
支持单页预览版和多页制作版。
多页版按固定格子区间切片，不得缩小整个大图塞进一页。
重叠边距默认 2 格（可配置 1–4 格），并在页面上标注拼接标记。
包含页码、行列坐标、色号图例和每色数量。

8.3 材料统计
