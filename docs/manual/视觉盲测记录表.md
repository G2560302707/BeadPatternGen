# 视觉盲测记录表（规格 10.3 · 人工盲测）

> 规格要求「视觉还原：人工盲测，不以单一 PSNR 或色差指标代替真实拼制效果」。
> 本表只记录真人观察结论。**禁止出现 0–100 分、还原度百分比、平均 ΔE 当"质量分"**；
> 诊断面板继续只显示孤立豆 / 碎片 / 细线 / 高色差格，不汇总成分数。

## 盲测方法

1. 每张图记录：图类型、网格、模式、抖动、色卡。
2. 观察者（真人）不看原图参数，只对着**打印或屏显的图纸**与实物拼豆对照，或对照
   原图与图纸并排视图，回答「能不能拼、哪里不像」。
3. 观察者姓名写进表格；同一张图可以有多个观察者，各占一行。
4. 结论只能三选一：`可接受` / `需加大网格` / `需换模式`（可附一句原因）。
