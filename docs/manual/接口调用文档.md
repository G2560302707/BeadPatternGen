## 1. 总体架构与分层

```
UI（React）
  │  startGeneration / cancelGeneration（src/state/generation.ts）
  ▼
Worker 消息协议（src/core/pipeline/protocol.ts）
  ▼
generate.worker.ts ── createWorkerRuntime ──► generatePattern（src/core/pipeline/generate.ts）
                                                │
                ┌───────────────────────────────┤ 纯函数层（无 DOM）
                ▼            ▼            ▼            ▼
          sampleToGrid   palette/     dithering/   modes/  quality/
         （src/core/sampling）         （src/core/*）
```

- **core 层全部是纯函数**，不依赖 DOM / Canvas，可在 Worker、测试、Node 环境直接调用。
- 唯一接触浏览器解码 API 的入口是 `decodeImageFile`（`src/features/image-import/decode-image.ts`）；Canvas 取像素在主线程完成，采样缓冲再交给 core。
- 数据模型 `BeadPattern` 字段名不可重命名（schema 1.0），见 [src/core/pattern/types.ts](../../src/core/pattern/types.ts)。

## 2. 核心流水线 generatePattern

位置：`src/core/pipeline/generate.ts`

```ts
function generatePattern(input: GenerateInput, hooks?: GenerateHooks): GenerateResult
```

固定执行顺序：采样校验 → 色卡子集 → 最近邻匹配 → 可选抖动 → 局部优化 → 诊断 → 统计 → 产出 `BeadPattern`。任一步抛错则整体失败，错误以 `PipelineError`（带 `code`）抛出，无隐式降级。

### GenerateInput

| 字段 | 类型 | 说明 |
|------|------|------|
| `rgb` | `Uint8ClampedArray` | 长度 `width*height*3`，每格 sRGB 0–255（来自 sampleToGrid） |
| `alpha` | `Uint8Array` | 长度 `width*height`，每格平均 alpha 0–255；`empty` 策略下 0 = 空格 |
| `width` / `height` | `number` | 网格尺寸，1–256，乘积 ≤ 65536 |
| `palette` | `BeadColor[]` | 全量色卡（code / name / hex / manufacturer / series?） |
| `paletteId` / `paletteVersion` | `string` | 色卡标识与版本，写入图纸 |
| `maxColors` | `number` | 工作色卡子集大小上限（1–178） |
| `mode` | `ImageMode` | `"photo" \| "anime" \| "logo" \| "landscape"` |
| `dithering` | `DitheringMode` | `"none" \| "floyd-steinberg"`；模式禁止抖动时传非 none 会抛 `E_INVALID_SETTINGS` |
| `colorMetric` | `ColorMetricName` | `"ciede2000" \| "oklab"` |
| `transparentPolicy` | `TransparentPolicy` | `"empty" \| "background"` |
| `ditherStrength` | `number` | FS 抖动强度 |
| `source` | `PatternSource` | 原图尺寸 / 宽高比 / 裁剪框 |
| `title` / `id` | `string` | 图纸标题与唯一 id |
| `now?` | `string` | 注入时间戳（测试用），缺省取当前时间 |
| `backgroundHex?` | `string` | `background` 策略下的背景色 `#RRGGBB` |

### GenerateHooks

| 字段 | 说明 |
|------|------|
| `onProgress?` | `(progress: { stage, done, total }) => void`；stage ∈ `"sample" \| "subset" \| "match" \| "dither" \| "refine" \| "diagnose"` |
| `shouldCancel?` | `() => boolean`；返回 true 时抛 `PipelineError("E_CANCELLED")`，不落地半成品 |

### GenerateResult

| 字段 | 类型 | 说明 |
|------|------|------|
| `pattern` | `BeadPattern` | 成品图纸（`cells: Int16Array`，-1 = 空格；已通过 `validatePattern`） |
| `diagnostic` | `DiagnosticReport` | 质量诊断（thin-line / isolated-bead / fragment / high-delta-e / low-resolution） |
| `stats` | `PatternStats` | 豆子总数、颜色数、逐色用量与占比 |

### 调用示例

```ts
import { generatePattern } from "./core/pipeline/generate";

const result = generatePattern(
  {
    rgb, alpha, width: 64, height: 64,
    palette: lockedPaletteColors(),
    paletteId: "artkal-s", paletteVersion: "f97ff428",
    maxColors: 24, mode: "photo", dithering: "none",
    colorMetric: "ciede2000", transparentPolicy: "empty",
    ditherStrength: 0.6,
    source: { originalWidth: 1024, originalHeight: 768, aspectRatio: 1024 / 768 },
    title: "我的图纸", id: crypto.randomUUID(),
  },
  {
    onProgress: (p) => console.log(p.stage, p.done, p.total),
    shouldCancel: () => cancelled,
  },
);
```

## 3. 面积采样 sampleToGrid

位置：`src/core/sampling/area-sample.ts`（纯函数，签名固定，不要改名或改参数顺序）

```ts
function sampleToGrid(
  img: ImageData,          // 结构上兼容即可：只读 width / height / data
  gridW: number,
  gridH: number,
  crop: CropRect,          // { x, y, width, height }，源图像素坐标
  alphaPolicy: "empty" | "background",
  backgroundHex?: string,  // alphaPolicy="background" 时必填
): SampledGrid
```

- `SampledGrid = { rgb: Uint8ClampedArray /* gridW*gridH*3 */, alpha: Uint8Array /* gridW*gridH */ }`，输出即 `generatePattern` 的输入。
- 语义：每格按源像素的**真实交叠面积加权**求平均（sRGB 空间，不转线性光）；透明像素的 RGB 按 `coverage × alpha/255` 预乘累计，避免污染。
- `empty` 策略：平均 alpha < 128（`EMPTY_ALPHA_THRESHOLD`）的格子输出 alpha=0（空格标记）。
- `background` 策略：逐像素合成到背景色，不产生空格；alpha 字段仍保留真实平均值。
- 放大网格（格区面积 < 1 平方像素）退化为格中心最近像素，永不出现 0 面积 / NaN。
- 错误：抛 `SamplingError`，code ∈ `INVALID_IMAGE | INVALID_GRID | INVALID_CROP | INVALID_ALPHA_POLICY | INVALID_BACKGROUND`。
- 调试辅助：`computeCellCoverage(...)` 返回单个格子的源像素覆盖明细（`spans` / `regionArea` / `nearestFallback`）。

## 4. 图片解码 decodeImageFile

位置：`src/features/image-import/decode-image.ts`（唯一允许接触浏览器解码 API 的图片入口）

```ts
function decodeImageFile(file: File): Promise<DecodedImage>
```

处理流程：文件大小 / 魔数 / 文件头尺寸硬限制（解码前拒绝）→ `createImageBitmap(file, { imageOrientation: "from-image" })` 处理 EXIF → 不可用时回退并按 EXIF Orientation 手动旋转 → 无法纠正方向则明确拒绝（`ORIENTATION_UNSUPPORTED`）。

```ts
interface DecodedImage {
  bitmap: ImageBitmap;          // 供 Canvas 取像素
  width: number; height: number;
  format: "jpeg" | "png" | "webp";
  exifOrientation: number;
  orientationApplied: boolean;
  warning: string | null;       // 非致命提示，null = 无
}
```

硬限制常量（`src/core/image/validate.ts`）：

| 常量 | 值 |
|------|----|
| `MAX_IMAGE_FILE_BYTES` | 20 MB |
| `MAX_IMAGE_DIMENSION` | 8192 px（单边） |
| `MAX_IMAGE_PIXELS` | 4000 万 |

错误：`ImageImportError`，code ∈ `EMPTY_FILE | FILE_TOO_LARGE | UNSUPPORTED_FORMAT | CORRUPT_HEADER | DIMENSION_LIMIT | DECODE_FAILED | ORIENTATION_UNSUPPORTED`，均 `recoverable = true`。

## 5. 图纸草稿 createDraftPattern

位置：`src/core/pattern/draft.ts`

```ts
function createDraftPattern(input: DraftPatternInput): BeadPattern
```

裁剪完成后调用：把 `source.crop` 与原始尺寸写进真实数据模型，`cells` 全部填充 `EMPTY_CELL`（-1），等待生成流水线填充。入参 `DraftPatternInput` 包含 `id / title / width / height / palette / mode / paletteId / paletteVersion / settings / source`（以及测试注入的 `now?`）。内部执行 `validatePattern`，source 非法抛 `PatternError("E_INVALID_SETTINGS")`。

## 6. 模式策略 getModeProfile

位置：`src/core/modes/profiles.ts`

```ts
function getModeProfile(mode: ImageMode): ModeProfile
```

返回冻结对象（禁止修改共享默认值，需局部调参请 `{ ...getModeProfile(mode), ... }` 复制）。未知 mode 抛 `RangeError`，绝不回退到 photo。

| 模式 | edgeProtectWeight | isolatedPenalty | colorMergeThreshold | localRefinePasses | 允许用户抖动 |
|------|-------------------|-----------------|---------------------|-------------------|--------------|
| photo | 3 | 6 | 5 | 2 | 是 |
| anime | 6 | 5 | 4 | 3 | 否 |
| logo | 8 | 3 | 2 | 2 | 否 |
| landscape | 2.5 | 8 | 6 | 3 | 是 |

优化目标函数：`score = ΔE(格子, 候选) + isolatedPenalty·是否造成孤立 + edgeProtectWeight·edgeStrength·是否改色`。调参方法与禁止事项见 `src/core/modes/PARAMS.md`。

## 7. Worker 消息协议

位置：`src/core/pipeline/protocol.ts`，运行时在 `src/core/pipeline/worker-runtime.ts`，Worker 入口 `src/workers/generate.worker.ts`。

### 请求（UI → Worker）

```ts
type WorkerRequest =
  | { type: "generate"; taskId: number; payload: GenerateInput }
  | { type: "cancel"; taskId: number };
```

### 响应（Worker → UI）

```ts
type WorkerResponse =
  | { type: "progress"; taskId; stage: PipelineStage; done; total }
  | { type: "done"; taskId; pattern: BeadPattern; diagnostic; stats }
  | { type: "error"; taskId; code: string; message: string };
```

### 关键约定

- **taskId 闸门**：响应落地前必须比对 `currentTaskId`（用 `createMessageGate()`），不匹配的响应直接丢弃——旧任务迟到结果不得覆盖新状态。
- **取消**：发 `{ type: "cancel", taskId }`；Worker 在阶段间隙检查，返回 `code: "E_CANCELLED"`。
- **零拷贝**：`done` 响应中 `pattern.cells` 的 `ArrayBuffer` 以 Transferable 传递（`transferableDone()`）；收到后 `cells` 属于接收方，不要再发给第三方。
- **UI 侧封装**：不要直接操作 Worker 时，可用 `src/state/generation.ts` 的 `startGeneration(input)` / `cancelGeneration()`。

### 接线示例

```ts
const worker = new Worker(new URL("./workers/generate.worker.ts", import.meta.url), { type: "module" });
const gate = createMessageGate();

worker.onmessage = (event) => {
  const message = gate.accept(event.data as WorkerResponse);
  if (!message) return; // 旧任务的迟到响应，丢弃
  switch (message.type) {
    case "progress": updateProgress(message.stage, progressPercent(message.done, message.total)); break;
    case "done": /* pattern.cells.buffer 已被 transfer，直接使用 */ break;
    case "error": if (message.code === "E_CANCELLED") { /* 回到可重试态 */ } break;
  }
};

const taskId = gate.nextTaskId();
worker.postMessage({ type: "generate", taskId, payload } satisfies WorkerRequest);
// 取消：worker.postMessage({ type: "cancel", taskId });
```

## 8. 导出接口

统一从 `src/export/index.ts` 导入。所有导出前先经 `assertExportReady(pattern)`（无统计则抛 `ExportError("E_STATS_INVARIANT")`）。

### PNG

```ts
function exportPng(pattern: BeadPattern, options?: PngExportOptions): Uint8Array
```

```ts
interface PngExportOptions {
  cellSize: 8 | 16 | 24 | 32;   // PNG_CELL_SIZES
  showGrid: boolean;
  showCoords: boolean;
  showCodes: boolean;           // 色号需 cellSize ≥ 16
  showLegend: boolean;
}
```

纯计算返回 PNG 字节，配合 `downloadBytes(bytes, filename)` 触发下载。同导出：`renderPngRgba` / `pngLayout`（底层渲染）、`MAX_CANVAS_EDGE = 8000`（Canvas 边长上限，内部按条带写入）。

### PDF（制作版）

```ts
function exportPdf(
  pattern: BeadPattern,
  options?: PdfExportOptions,   // { paper: "a4"|"a3"|"letter"; mode: "preview"|"make"; overlap: 0–4; showCodes: boolean }
): Promise<PdfExportResult>
```

`PdfExportResult` 含 `bytes / patternPageCount / legendPageCount / cellsDrawnPerPage / slices / cellPt / colPages / rowPages`。布局规划可单独调用：`planMakeLayout(width, height, paper, overlap)`、`pdfPageCapacity(paper, cellPt?, withRuler?)`、`balancedCapacity(...)`。

### CSV / JSON

```ts
function exportCsv(pattern: BeadPattern): Uint8Array        // "色号,色名,HEX,数量,占比"，占比合计精确补差到 100
function exportProjectJson(pattern: BeadPattern): string     // schemaVersion 1.0 项目 JSON
function parseProjectJson(raw: string | unknown): BeadPattern // 导入解析（严格校验）
```

### 下载

```ts
function downloadBytes(bytes: Uint8Array, filename: string): void
function downloadText(text: string, filename: string): void
```

导出错误：`ExportError`，code ∈ `E_STATS_INVARIANT | E_NO_PATTERN | E_EXPORT | E_INVALID_OPTION`。

## 9. 存储接口 ProjectRepository

位置：`src/storage/project-repository.ts`，基于 IndexedDB（三个 store：projects / patterns / thumbs）。用 `createProjectRepository()` 创建，或直接用单例 `defaultRepository.get()`。

```ts
interface ProjectRepository {
  save(pattern: BeadPattern): Promise<ProjectMeta>;      // 校验 + 写元数据/记录/8px 缩略图
  load(id: string): Promise<LoadedProject>;              // { meta, pattern }；不存在抛 E_NOT_FOUND
  list(): Promise<ProjectMeta[]>;                        // 按 updatedAt 降序
  remove(id: string): Promise<void>;                     // 三 store 一并删除
  exists(id: string): Promise<boolean>;
  estimate(): Promise<QuotaSnapshot>;                    // { usage, quota, ratio, warn }；warn = ratio ≥ 0.8
  purgeThumbnails(): Promise<number>;                    // 清空缩略图，返回清理条数
}
```

配套函数：

```ts
function importPatternJson(raw: string): BeadPattern;  // 上限校验 → decodeProject → 格子索引起草卡范围检查
function assertImportLimits(raw: unknown): void;        // JSON ≤ 8MB、根节点为对象、字符串 ≤ 4096、cells ≤ 65536
function assemblePattern(record, width, height): BeadPattern; // 从存储记录重建 BeadPattern
```

错误：`StorageError`，常见 code：`E_IDB_UNAVAILABLE / E_NOT_FOUND / E_CORRUPT_RECORD / E_IMPORT_TOO_LARGE / E_IMPORT_SCHEMA / E_IMPORT_SIZE / E_IMPORT_STRING / E_IMPORT_INDEX`。

## 10. 错误码汇总

| 模块 | 错误类 | code |
|------|--------|------|
| 生成流水线 | `PipelineError` | `E_CANCELLED`（用户取消）、`E_INVALID_SAMPLE`（rgb/alpha 长度不符）、`E_INVALID_SETTINGS`（色卡为空 / 模式禁抖等）、`E_PIPELINE`（内部异常，wrap 后的兜底码） |
| 图片导入 | `ImageImportError` | `EMPTY_FILE / FILE_TOO_LARGE / UNSUPPORTED_FORMAT / CORRUPT_HEADER / DIMENSION_LIMIT / DECODE_FAILED / ORIENTATION_UNSUPPORTED` |
| 采样 | `SamplingError` | `INVALID_IMAGE / INVALID_GRID / INVALID_CROP / INVALID_ALPHA_POLICY / INVALID_BACKGROUND` |
| 图纸数据 | `PatternError` | `PATTERN_ERROR_CODES`：`E_CELLS_LENGTH / E_INDEX_OUT_OF_RANGE / E_DUP_CODE / E_DUP_HEX / E_NON_POSITIVE_DIMENSION / E_DIMENSION_LIMIT / E_INVALID_HEX / E_EMPTY_FIELD` 等（见 src/core/pattern/errors.ts） |
| 模式策略 | `RangeError` | 未知 mode 直接抛出，不回退 |
| 导出 | `ExportError` | `E_STATS_INVARIANT / E_NO_PATTERN / E_EXPORT / E_INVALID_OPTION` |
| 存储 | `StorageError` | 见第 9 节 |

所有错误类都带 `code` 属性与 `name`，UI 按 code 渲染可恢复提示；取消必须使用 `E_CANCELLED`。

## 11. 端到端调用示例

在浏览器主线程中从一张图片文件生成图纸并导出 PNG（省略 UI 状态管理）：

```ts
import { decodeImageFile } from "./features/image-import/decode-image";
import { sampleToGrid } from "./core/sampling/area-sample";
import { createDraftPattern } from "./core/pattern/draft";
import { generatePattern } from "./core/pipeline/generate";
import { exportPng, downloadBytes } from "./export";
import { lockedPalette, lockedPaletteColors } from "./features/palette-panel/locked-palette";

// 1. 解码（含 EXIF 纠偏与硬限制校验）
const decoded = await decodeImageFile(file);

// 2. Canvas 取像素（core 层不碰 DOM，这步留在主线程）
const canvas = document.createElement("canvas");
canvas.width = decoded.width;
canvas.height = decoded.height;
const ctx = canvas.getContext("2d")!;
ctx.drawImage(decoded.bitmap, 0, 0);
const imageData = ctx.getImageData(0, 0, decoded.width, decoded.height);

// 3. 面积采样到 64×64 网格
const crop = { x: 0, y: 0, width: decoded.width, height: decoded.height };
const { rgb, alpha } = sampleToGrid(imageData, 64, 64, crop, "empty");

// 4. 直接生成（也可走第 7 节的 Worker 协议）
const result = generatePattern({
  rgb, alpha, width: 64, height: 64,
  palette: lockedPaletteColors(),
  paletteId: lockedPalette.paletteId,
  paletteVersion: lockedPalette.version,
  maxColors: 24, mode: "photo", dithering: "none",
  colorMetric: "ciede2000", transparentPolicy: "empty",
  ditherStrength: 0.6,
  source: {
    originalWidth: decoded.width, originalHeight: decoded.height,
    aspectRatio: decoded.width / decoded.height, crop,
  },
  title: file.name, id: crypto.randomUUID(),
});

// 5. 导出
downloadBytes(exportPng(result.pattern, { cellSize: 16, showGrid: true, showCoords: true, showCodes: true, showLegend: true }), "pattern.png");
```

生产路径建议走 Worker（第 7 节），避免大网格匹配阻塞主线程；`src/state/generation.ts` 已封装好进度与取消。
