## 1. 系统简介

豆豆图纸（Dudu Pattern）把一张普通图片转换成可执行的拼豆图纸：确定网格尺寸、从色卡中挑选颜色、逐格匹配，并输出用于制作和分享的 PNG / PDF / CSV / JSON 文件。应用内右上角「📖 使用说明」可随时打开与本文档同源的帮助页。

核心特点：

- **完全本地运行**：图片解码、采样、颜色匹配全部在浏览器内完成，**任何图片都不会上传到服务器**。
- **分步引导**：首页 → 导入 → 抠图构图（可选）→ 画布裁剪 → 调色生成 → 精修 → 导出分享，每步一个页面，顶部步进器随时跳转。
- **八套主题**：默认「樱粉少女」（二次元可爱风），另有香芋啵啵 / 抹茶手账 / 海盐汽水 / 月夜宫阙（暗色）/ 云朵白 / 复古信笺（宋体优雅）/ 像素工坊（缝合像素），右上角一键切换并记忆。
- **四种图像模式**：针对照片、二次元、图标 / 文字、风景分别采用不同的优化策略。
- **专业色差度量**：使用 CIEDE2000 或 Oklab 计算颜色差异，比肉眼近似匹配更准确。
- **质量诊断**：自动检测细线断裂、孤立豆、碎片、色差过大、分辨率不足等问题。
- **统一分享卡片导出**：所有视觉导出（分享图 / 图纸 PNG / SVG / PDF）共用同一套「分享卡片」版式，观感一致。

## 2. 运行环境与启动

| 项目 | 要求 |
|------|------|
| 浏览器 | 近两年的 Chrome / Edge / Firefox / Safari（需支持 Web Worker 与 IndexedDB） |
| 开发启动 | `pnpm install` 后执行 `pnpm dev`，浏览器打开提示的本地地址 |
| 构建产物 | `pnpm build`，可用任意静态文件服务器托管 |

系统无账号、无登录、无后端依赖。

## 3. 界面布局

产品为「一个家 + 六步流程」的页面结构，全局外壳 = 品牌栏 + 步进器 + 状态栏：

```
┌──────────────────────────────────────────────────────────┐
│ 豆豆图纸   [色卡信息] [🎨主题切换] [📖使用说明]              │
│ ①导入 ─ ②抠图构图·可选 ─ ③画布裁剪 ─ ④调色生成 ─ ⑤精修 ─ ⑥导出 │
├──────────────────────────────────────────────────────────┤
│                  （当前步骤页面内容）                        │
├──────────────────────────────────────────────────────────┤
│ 状态栏：原图尺寸 · 图纸尺寸 · 豆子数 · 生成进度 · 保存状态 ·   │
│        隐私提示                                            │
└──────────────────────────────────────────────────────────┘
```

- **首页**：开始制作 / 导入工程 JSON / 新手教程，「我的作品」卡片墙（保存过的图纸带缩略图，可打开 / 删除）。
- **步骤页**：左侧参数面板 + 右侧实时预览舞台（精修页为画布 + 工具栏 + 右侧色卡栏）。
- **步进器**：节点是拼豆圆片，已完成的步点亮，当前步放大呼吸；点击任意一步即可跳转，缺前置条件时页面会给出引导而不是报错。
- **主题切换**：右上角弹出菜单，8 套主题以迷你色卡预览，选择立即生效并记忆；月夜宫阙为暗色主题（图纸画布区仍保持亮底以辨色）。
- **使用说明**：右上角「📖 使用说明」打开应用内帮助页（`#/help`），内容与本说明书同源，六步流程 / 导出格式 / 常见问题一页看完。
- 生成过程中显示六阶段进度：**采样 → 选色 → 匹配 → 抖动 → 优化 → 诊断**。

## 4. 快速上手（六步出图）

1. **导入**（`#/make/import`）：拖入 / 选择图片，或直接 Ctrl+V 粘贴截图；没有图可以先用内置示例（爱心 / 星星 / 草莓 / 日落风景）玩一把。
2. **抠图构图**（可选，`#/make/compose`）：一键识别主体并摆到 C 位，可手涂蒙版修补、换背景；不需要就点「跳过」。
3. **画布裁剪**（`#/make/canvas`）：调整裁剪框、设定格数（每格 = 一颗豆），可用市售板子预设（5mm 29×29 / 2.6mm 26×26），点「应用裁剪并采样」。
4. **调色生成**（`#/make/generate`）：选画风卡片（照片 / 二次元 / 图标文字 / 风景）和最大颜色数，点「生成图纸」；抖动与色差度量在「高级选项」里。生成完成自动进入精修。
5. **精修**（`#/make/refine`）：画笔 / 橡皮 / 吸色 / 框选 / 套索 / 撤销重做，右侧色卡点一下即选为画笔色。画笔再拖一遍已涂的区域即恢复生成色（再上一遍 = 取消）；套索拖动圈选会累加（可圈多块），点一下格子即可勾选 / 取消勾选，工具栏「取消勾选」一键清空；系统给出孤立豆等诊断。
6. **导出分享**（`#/make/export`）：分享图纸 PNG（社交卡片，可带原图 / 烫后对比与水印）、图纸 PNG、SVG 矢量图、制作版 PDF（照着拼）、预览版 PDF、采购 CSV、工程 JSON，全部为统一「分享卡片」版式；可「保存到本机」进入首页作品库。

## 5. 功能详解

### 5.1 图片输入

| 限制项 | 数值 |
|--------|------|
| 支持格式 | JPG、PNG、WebP（按文件头魔数识别，改扩展名无法绕过） |
| 单文件大小 | ≤ 20 MB |
| 单边尺寸 | ≤ 8192 px |
| 总像素 | ≤ 4000 万 |
| EXIF 方向 | 自动读取并纠正（手机竖拍照片不会倒置） |

超限或无法识别的文件会在解码前被拒绝，并给出可恢复的中文提示。

### 5.2 裁剪

- 导入后自动按当前网格宽高比计算裁剪框。
- 手动调整裁剪框后，采样以裁剪区域为准；裁剪信息会随图纸一起保存（记录在 `source.crop` 中）。

### 5.3 网格采样

采样决定"图纸的分辨率"——每个网格格子对应成品中的一颗拼豆。

- **网格尺寸**：宽、高各 1–256，格数乘积上限 65536（256 × 256）。网格越大越精细，豆子数越多。
- **尺寸适配模式（fitMode）**：裁剪区域与网格比例不完全一致时，决定拉伸 / 适配方式。
- **透明处理（两个选项）**：
  - **保留空格**：透明区域不摆豆（alpha 平均值 < 128 的格子视为空格）。适合图标、贴纸类图。
  - **合成背景色**：把透明像素按透明度混合到指定背景色上，整张图都有豆。适合不透底的制作。

### 5.4 生成参数

**模式（四个预设策略）**

| 模式 | 适用内容 | 优化重点 | 抖动 |
|------|----------|----------|------|
| 照片 photo | 人物、宠物、实拍 | 保护五官与明暗层次 | 允许开启 |
| 二次元 anime | 动漫角色、插画 | 保护描边、眼睛高光、色块边界 | 强制关闭 |
| 图标 / 文字 logo | 图标、文字、透明 PNG | 保护硬边与字母，透明区永不填色 | 强制关闭 |
| 风景 landscape | 天空、山水、水面 | 消除渐变中的杂点，允许更积极的合并 | 允许开启 |

**豆子规格与板子预设**：在「图纸与透明」区选择豆子规格（2.6mm 小豆默认联动 MARD 221 色卡；5mm 大豆联动 Artkal S 色卡），并从市售板子规格下拉中一键套用：5mm 标准板 29×29（可拼 58×58 / 87×87），2.6mm 小板 26×26（市售 52 钉大板 = 2×2 小板即 52×52，78 钉 = 3×3 即 78×78）。下方实时显示拼板数与成品厘米尺寸（按钉距 5mm / 2.8mm 换算）。自由输入宽高仍然可用。

**最大颜色数**：1 – 当前色卡色数（MARD 221 为 221，Artkal S 为 178）。系统先从全色卡中挑出与图片最相关的前 N 色，再逐格匹配，色数越少成品越简洁、购买豆子越省事。

**抖动（Floyd–Steinberg）**：通过在相邻格子间分散色差来模拟渐变，适合照片 / 风景的大面积渐变；二次元和图标模式强制关闭，避免碎点破坏色块与文字。

**色差度量**：
- **CIEDE2000**：感知色差标准，整体最准确（推荐默认）。
- **Oklab**：计算更均匀，某些高饱和图上表现更好。

### 5.5 生成过程与进度

点击生成后，生成任务在后台 Worker 中执行，界面显示六阶段进度：

采样 → 选色 → 匹配 → 抖动 → 优化 → 诊断

- 生成期间参数不可修改，可随时**取消**；取消后不会留下半成品图纸。
- 生成完成后进入"图纸只读"状态：预览区显示成品图纸，色卡面板显示用色。

### 5.6 质量诊断

生成完成后自动出具诊断报告，问题类型：

| 诊断代码 | 含义 |
|----------|------|
| thin-line | 细线（1 格宽的线条）存在断裂风险 |
| isolated-bead | 孤立豆：四周没有同色相邻的单格 |
| fragment | 碎片：过小的同色连通块，实际拼制时难以处理 |
| high-delta-e | 色差过大：某些格子在现有色卡内找不到接近的颜色 |
| low-resolution | 分辨率不足：网格尺寸偏小，可能丢失细节 |

### 5.7 导出

生成图纸后方可导出。颜色始终读取当前图纸色卡，不会重新量化。**所有视觉导出共用同一套「分享卡片」版式**（`src/export/card-style.ts` 单一来源）：暖粉纸底、页眉信息栏、白色圆角图纸卡 + 红色 L 角标、每 5 格分区线、按用量排序的圆角色卡图例与脚注，观感一致。

- **分享图纸 PNG**：竖版社交卡片——页眉信息栏（规格 / 色板 / 色数 / 用豆）、白色圆角图纸卡片（彩色格子 + 格内色号 + 每 5 格粗线 + 行列号）、色卡图例、底部「原图 / 烫后效果模拟」对比与脚注。可选 2x 高清、对比区开关与自定义水印；未导入原图时自动省略原图对比。适合直接发社交平台或发给买家参考。
- **图纸 PNG**：与分享图同款卡片版式的工程导出（纯像素渲染、无抗锯齿，颜色逐格精确可采样）——ASCII 信息栏（SIZE / PALETTE / COLORS / BEADS + BEAD CHART 标签）、圆角图纸卡、上 / 下 / 左 / 右四边每 5 格行列号、圆角图例。格尺寸 8 / 16 / 24 / 32 / 48 / 64 px 可选，格子越大像素越多、放大查看越清晰；可勾选网格、图例、行列号、每格色号（色号需格尺寸 ≥ 16px，字号随格尺寸放大）；画布超限时自动缩小格点。
- **SVG 矢量图**：与图纸 PNG 同版式的矢量版本（rect / line / text 图元 + 系统字体），浏览器、设计软件里任意放大都不模糊，适合印刷或长图缩放查看；中文信息栏直接用中文文案。
- **PDF（制作版）**：卡片版式（页眉标题 + 页码/切片信息 + 规格摘要 + 红描边「拼豆图纸分享」标签，中文走内嵌 Noto Sans SC 子集字体，字体缺失时自动回退英文）。纸张 A4 / A3 / Letter；重叠格 0–4（相邻页重复边缘格，方便对齐拼贴）；"整图缩放到单页"默认开启——超出单页容量时自动用小数格点把整图缩放进一页（矢量输出放大不失真；格点过小时每格色号自动省略、标尺只在每 5/10 格分区线处标注），关闭后回到按容量分页；"包含色表页"默认开启——圆角色块 + 色号 + 用量，按用量降序。
- **PDF（预览版）**：单页整图 + 完整信息栏（规格 / 色板 / 色数 / 用豆），同样附带色表页。
- **CSV**：用色清单（色号、色名、HEX、数量、占比），可直接拿去采购。
- **JSON**：完整项目文件，可重新导入本系统恢复图纸。

### 5.8 状态栏信息

依次显示：原图尺寸 → 图纸 / 草稿尺寸 → 豆子总数（或空格数）→ 生成进度百分比 → 保存状态 → 隐私提示。

## 6. 保存与项目管理

- **本地保存**：图纸保存到浏览器的 IndexedDB（项目元数据 + 格子数据 + 缩略图），状态栏显示"保存中 / 已保存"。
- **存储配额**：用量达到配额 80% 时提示；可清理缩略图释放空间。
- **JSON 导入**：导入限 8MB 以内、结构合法的项目文件；格子索引超出色卡范围会被拒绝。

## 7. 隐私说明

- 所有处理（解码、采样、匹配、导出）都在你的浏览器内完成，**图片与图纸不会上传**。
- 清除浏览器数据会删除本地保存的项目，重要图纸请导出 JSON 备份。

## 8. 常见问题与错误提示

| 现象 / 提示 | 原因与处理 |
|-------------|------------|
| 文件超过 20MB 上限 | 压缩或缩小图片后重试 |
| 不是有效的 JPG / PNG / WebP | 文件头校验失败（即使扩展名对也不行），请换图或重新导出 |
| 图片超过单边 8192px / 4000 万像素 | 先在图片工具中缩小 |
| 当前模式强制关闭抖动 | 二次元 / 图标模式的设计行为，防止碎点 |
| 页数较多，可改用 A3 | 制作版 PDF 分页过多时的建议 |
| JSON 超过 8MB / 网格超上限 | 导入文件不合法，拒绝导入 |
| 找不到项目 id | 本地库中没有该项目（可能已被清除浏览器数据删除） |
| 当前环境没有 IndexedDB | 浏览器不支持或隐私模式禁用了 IndexedDB，无法本地保存 |

## 9. 已知限制

- 色卡可在 MARD 221（2.6mm 小豆）与 Artkal S（5mm 大豆）之间切换，均为社区整理的测量色值，与实物可能存在个别色差（参考市面同类工具的通用做法，图纸上亦标注「色号与用量仅供参考」）。暂不支持导入自定义色卡。
- 图纸网格上限 256 × 256。
- 极大图片与大网格组合时，生成耗时随格数线性增长，请耐心等待或缩小网格。
