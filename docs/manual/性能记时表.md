# 性能记时表（规格 9.1 · 人工记录）

> 规格要求「基准图片多次运行，记录 P50/P95」。阈值（50×50 ≤ 1s、100×100 ≤ 3s、
> 200×200 ≤ 10s）**不作为 CI 失败门禁**——机器差异会误杀。本表只记录实测数字；
> 没有实测就留空，禁止编造或估算。
>
> 应用内现状栏（状态栏「生成完成 · 耗时 X.Xs」）是本机单次实测，
> 记录时可作参考，但正式表格以多次运行取 P50 / P95 为准。

## 记录方式

1. 固定一张基准图（记录文件名与尺寸），同一参数连续生成 **5 次**，取 P50 与 P95。
2. 每次生成前清掉上一张图纸（重新点「生成图纸」即可，任务计时从发起到结果落地）。
3. 状态栏会显示单次耗时；也可用 DevTools Performance 面板核对。
4. **200×200 预览首帧**用浏览器 DevTools → Performance 面板测量（含 Canvas 绘制），
   不要用 Node Fake Canvas 的数字当结论。
5. 换机器 / 换浏览器 / 换色卡后另起一列，不混用。
