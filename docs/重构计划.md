# 拼豆图纸生成器 · 多页面 UI 重构计划

> 版本：v1.1 · 撰写日期：2026-10-25 · **状态：P0–P2 已完成，E2E 14/14 绿；P3 打磨与 P4 商业化收尾进行中**
> 2026-10-25 追加：核心算法层完成 1.2 升级（主体识别残缺 + 小尺寸失真修复，默认分割模型换 isnet-anime），详见《算法升级-1.2.md》；`pnpm quality:run` 为算法回归工具。
> 已落地：路由分页（首页 + 六步）、6 套主题、樱粉少女旗舰主题、自托管字体子集（`pnpm fonts`）、豆豆吉祥物、首页作品库（含缩略图）、示例图库（`pnpm samples`）、移动端适配、隐私政策/用户协议页、SEO 元信息与 favicon。
> 目标：在**功能零删减**的前提下，把单页工作台重构为「分步页面」产品形态；以设计师视角重做视觉系统（可爱风 / 二次元少女风旗舰主题）；按商业化标准补齐基础设施，为推广做准备。
> 原则：**核心算法层（src/core、export、render、storage、workers）一行不动**，重构只发生在 UI 层与交互组织层。

## 一、现状诊断（为什么要重构）

### 1.1 现状问题

| 问题 | 具体表现 |
| --- | --- |
| 所有功能挤在一页 | 左栏塞了导入、裁剪、采样、生成、导出、保存 6 组控件；二期又叠加了抠图构图工作台，左右模式切换认知负担重 |
| 新用户无从下手 | 打开后面对 20+ 个参数控件，没有引导，不知道「先做什么再做什么」 |
| 视觉是工具风 | 蓝白工程配色 + 系统字体，与目标用户（小红书手工圈、女性、二次元爱好者）审美错位 |
| 无产品外壳 | 没有首页 / 作品库入口 / 教程 / 主题切换，不具备一个「可推广的网站」的完整形态 |
| 桌面优先 | 三栏布局在手机上不可用，而推广主阵地小红书的流量以手机为主 |

## 二、新信息架构（IA）：六步 + 一个家

### 2.1 总览

```
🏠 首页（作品库）
   └─ 开始制作 ──▶ 进入引导流程
┌────────────────────────────────────────────────┐
│  S1 导入  →  S2 抠图构图(可选) → S3 画布与裁剪    │
│      →  S4 调色生成  →  S5 精修  →  S6 导出分享  │
└────────────────────────────────────────────────┘
```

- **分步但不强制串行**：顶部步进器（Stepper）随时可点跳转；未满足前置条件的步骤显示友好提示并引导回上一步，而不是粗暴禁止。
- S2 是「可选步」，默认可跳过（跳过 = 不抠图直接用整图），在步进器上标注「可选」。
- 路由即页面：`#/` 首页、`#/make/import`、`#/make/compose`、`#/make/canvas`、`#/make/generate`、`#/make/refine`、`#/make/export`。用 `react-router-dom` 的 **HashRouter**（纯静态托管零配置可用；后续有服务端 rewrite 时可无痛切 BrowserRouter）。
- 页面组件全部 `React.lazy` 懒加载，按步分包。

### 2.2 每页职责（一句话定位，可直接当页面文案）

| 页面 | 路由 | 一句话 | 前置条件 |
| --- | --- | --- | --- |
| 首页 | `#/` | 你的拼豆图纸工作室：新建、继续、教程 | 无 |
| S1 导入 | `#/make/import` | 选一张图，我们本地处理，绝不上传 | 无 |
| S2 抠图构图 | `#/make/compose` | 让主角站上 C 位：一键抠出主体，摆好姿势（可跳过） | 有图片 |
| S3 画布与裁剪 | `#/make/canvas` | 决定图纸多大：裁剪 + 格数 + 板子规格 | 有图片 |
| S4 调色生成 | `#/make/generate` | 挑模式、定色数，一键生成图纸 | 已采样 |
| S5 精修 | `#/make/refine` | 逐格微调：画笔、橡皮、吸色、选区 | 有图纸 |
| S6 导出分享 | `#/make/export` | 带走你的图纸：分享图、PDF、采购清单 | 有图纸 |

## 三、设计系统（Design System）

### 3.1 主题系统机制

- 设计令牌（Design Tokens）全部用 CSS 自定义属性，`<html data-theme="sakura">` 切换；`styles/themes/*.css` 每主题一个文件，只改令牌不动组件。
- localStorage 记忆用户选择；首次访问跟随 `prefers-color-scheme` 猜一个浅色主题。
- **每个主题都做成「可爱系家族」**，差异在色相与性格，不再有工程感默认样式。

### 3.2 主题清单（首发 6 款）

| 主题 | id | 性格 | 色彩基调 |
| --- | --- | --- | --- |
| 🌸 **樱粉少女（旗舰 · 默认）** | `sakura` | 二次元少女风，精心设计见 3.4 | 樱花粉 × 奶油白 × 奶蓝点缀 |
| 🍇 香芋啵啵 | `taro` | 梦幻紫罗兰 | 香芋紫 × 淡雾白 × 葡萄点缀 |
| 🍵 抹茶奶绿 | `matcha` | 治愈系手账 | 抹茶绿 × 米白 × 奶油黄 |
| 🥤 海盐汽水 | `soda` | 清爽元气（最接近现版气质） | 海盐蓝 × 云白 × 柠檬 |
| 🌙 月夜宫阙 | `luna` | 二次元暗色：深夜紫底 + 霓虹粉青点缀，图纸画布区强制亮底保证辨色 | 深紫黑 × 霓虹粉/青 |
| ☁️ 云朵白 | `cloud` | 素雅工作色，长时间使用不累 | 暖白 × 浅灰蓝 |

> 暗色主题特例：图纸预览 / 精修画布 / 导出预览永远使用亮底 + 原色渲染，避免色觉失真；只有周边 UI 变暗。

### 3.3 字体方案（可爱风，且不破坏「零外站请求」红线）

现有 E2E 验证「外站请求数为零」且已移除 CDN 字体，新字体必须**全部自托管**，且只选可商用的开源授权字体（OFL）。

| 用途 | 字体 | 授权 | 说明 |
| --- | --- | --- | --- |
| 品牌 / 标题 / 按钮 / 步进器 / 徽章 | **站酷快乐体 ZCOOL KuaiLe** | SIL OFL，可商用 | 圆润手写卡通风，可爱风的「门面」 |
| 数字与拉丁（用量、尺寸、色号） | **Baloo 2** | SIL OFL | 圆滚滚的数字，与快乐体同气质 |
| 正文 / 表单 / 说明 | 系统圆润栈：`MiSans, PingFang SC, HarmonyOS Sans SC, Microsoft YaHei` | — | 正文可读性优先；中文全量字体太大，正文用系统栈 |
| 手账点缀（空态文案、引用、提示语） | 霞鹜文楷 LXGW WenKai Screen（可选第三期再加） | SIL OFL | 手写感，用于「豆豆碎碎念」气泡 |

**工程做法**：新增 `scripts/build-fonts.mjs` —— 从官方仓库（走 gh-proxy 下载）取 TTF → 用 `cn-font-split` 按站点词汇表（约 1200 字）子集化 + unicode-range 分片 woff2 → 产出至 `public/fonts/` 随构建分发。快乐体子集预计 250–400KB，Baloo 2 拉丁子集约 30KB；分片懒加载，不阻塞首屏。仓库内附 OFL 许可与来源 NOTICE。

**回退策略**：用户输入的动态文本（文件名、水印）超出子集时自动回退系统字体，不缺字、不闪烁（`font-display: swap`）。

### 3.4 🌸 旗舰主题「樱粉少女」详细规格（精心设计）

**设计概念**：「云朵上的拼豆小铺」——奶油底色上漂浮樱花与闪片，控件像糖果和贴纸，吉祥物豆豆全程陪伴。所有圆角、描边、阴影都往「软、甜、Q」做，但对比度仍满足 WCAG AA。

**色彩令牌**：

```css
[data-theme="sakura"] {
  /* 底与面 */
  --bg: #FFF4F8;            /* 樱花奶油底 */
  --bg-image:               /* 背景：极淡格纹 + 圆点 + 顶部粉云渐变 */
    radial-gradient(circle at 12px 12px, #FFE3EE 2.4px, transparent 3px),
    linear-gradient(180deg, #FFE9F2 0%, var(--bg) 320px);
  --surface: #FFFFFF;       /* 卡片 */
  --surface-2: #FFF9FC;     /* 卡片内嵌区 */
  --ink: #58424E;           /* 可可梅子色（比纯黑柔软） */
  --ink-soft: #A88C9B;
  --line: #F7D9E5;

  /* 主色与点缀 */
  --primary: #F76E9C;       /* 樱花粉主操作 */
  --primary-deep: #E14D82;  /* 糖果按钮底边 */
  --primary-soft: #FFDCE9;  /* 选中底 / 标签底 */
  --accent-blue: #8FC7FF;   /* 奶蓝点缀（次级选中） */
  --accent-mint: #A8E6CF;   /* 成功 */
  --accent-lemon: #FFE9A8;  /* 警示柔和底 */
  --danger: #F26D6D;

  /* 形状与手感 */
  --radius-lg: 22px;  --radius-md: 14px;  --radius-full: 999px;
  --border-w: 2px;          /* 贴纸感粗描边 */
  --shadow: 0 6px 0 var(--line), 0 14px 30px rgba(247,110,156,.14);
}
```

**标志性组件语言**（全主题共用机制，令牌不同）：

- **糖果按钮**：实心粉底 + 底部 4px 深色边（按压时 `translateY(3px)` 底边变 1px），果冻感；主按钮带微光高光。
- **贴纸卡片**：白底粗圆角 + 2px 描边；重点卡片描边用主题点缀色虚线（和纸胶带感），可带 1° 微旋转的「贴纸徽章」。
- **波点/格纹背景** + 四角樱花瓣漂浮装饰（CSS 绘制，`prefers-reduced-motion` 时静止）。
- **步进器**：节点是拼豆圆片，当前步的豆豆吉祥物坐在上面，已完成的豆片「点亮」。
- **豆豆吉祥物（Mascot「豆豆」）**：一颗圆拼豆 + 腮红 + 高光点，纯内联 SVG 组件，零外链。状态：待机 / 开心（成功）/ 加油（生成中，随进度跑）/ 委屈（错误）/ 庆祝（导出完成 + 彩带）。用于：空态、加载、错误、成功、教程气泡。
- **微动效规范**：回弹曲线 `cubic-bezier(.34,1.56,.64,1)`，时长 150–250ms；导出成功彩带一次；全部动效尊重 `prefers-reduced-motion`。

### 3.5 基础组件库（`src/ui/`，新建）

BeadButton（primary/secondary/ghost/danger）、Card、Stepper、Chip、Tag、Switch、Slider、SegmentedControl、Select、Modal、Toast（替代部分 alert 式错误）、Popover、Tabs、Dropzone、ProgressBar（豆豆奔跑版）、Tooltip、ColorSwatch、EmptyState / ErrorNotice / LoadingNotice（重设计现有三件套）。全部只消费令牌，天然随主题换肤。

### 3.6 版式与栅格

- 基准字号 14px / 行高 1.7；标题用快乐体：H1 24 / H2 18 / H3 15。
- 间距 4 的倍数；页面最大宽 1200px 居中；步骤页采用「左侧参数栏 320px + 右侧舞台自适应」的两栏（比现在的三栏少一层），手机上折叠为上下堆叠。
- 移动端（≤768px）：步进器折叠为「第 2/6 步 · 抠图」胶囊；参数栏变为底部抽屉（Drawer）；画布支持双指缩放。

## 五、商业化基建（推广前的清单）

- **SEO / 传播**：每页 title/description；OG 分享卡（标题 + 豆豆图）；favicon 套装；robots.txt。落地页文案突出「免费 · 本地处理 · 不上传」三个卖点。
- **响应式 + 性能**：全站适配手机；路由分包；字体子集；Lighthouse 目标：性能 ≥ 90、无障碍 ≥ 95。
- **教程与内容**：内置 3 步新手引导（首次访问）+ 教程页（图文，走本地资产）；为小红书准备 3 篇模板文案（工具自带，不阻塞开发）。

### 风险与对策

| 风险 | 对策 |
| --- | --- |
