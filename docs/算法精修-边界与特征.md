# 精修升级 1.3：主体描边 × 边界锐化 × 特征保护锁

> 2026-10-25 · 目标：解决「主体边界感弱（没有描边概念）」「细微特征被抹」「色块边缘乱」三个精修阶段问题。
> 依据：参考图集实测（`docs/市面图纸对齐-分析与路线.md`）——市面优秀图纸主体带 1 格深色描边，
> 描边色随主体色调变化（暖调主体用暖深灰 M15 系、普通动漫用近黑 H7 系、深色主体用中灰避免黑上黑），
> 5 色极简图纸也固定保留 1 个深色描边位。

## 问题定位（现状管线）

```
sample → k-means 选色 → 最近邻 → flattenRegions(多数投票+碎片合并) → refineLocally(孤立豆修复)
```

1. **无描边**：主体轮廓格与内部格同权重参与量化，轮廓被采样平均稀释——主体「融」在背景里。
2. **边界噪点**：两色块交界格的采样色是两侧平均的中间色，量化后随机落到任一侧，边缘呈锯齿噪点带。
3. **特征误伤**：flatten 的多数投票 / refine 的孤立豆修复只靠 ΔE 门槛间接保护小特征（眼高光、瞳孔、
   小图标），没有显式「这是有意细节」的概念；反过来没有保护锁时，平整化参数也不敢调强。

## 升级设计

### 1. 主体描边（Rim Outline，量化前）

- **轮廓检测**：非空格的 8 邻域中存在空格或画布外 → 该格为轮廓格（8 邻接保证斜向轮廓连续不断点）。
  仅 `empty` 透明策略生效（背景策略没有空格，无从谈轮廓）。
- **描边锚色（看主体定，确定性规则）**：
  - 主体平均明度 L* < 45（深色主体）→ 目标 `#2C2C2C` 中灰（黑上黑无分离度）；
  - 主体色相角落在暖扇区（Lab atan2(b,a) ∈ 40°..85° 且彩度 > 8）→ 目标 `#4A3F38` 暖深灰；
  - 其余 → 目标 `#111111` 近黑。
  - 目标色再映射到全色卡最近的真实色（描边必是真实色号）。
- **色位预留**：`selectPaletteSubset` 先选 `maxColors-1` 个，再并入描边色下标（去重排序）。
  保证任何 maxColors ≥ 3 的生成里描边色一定在图纸色板内。maxColors < 3 时描边整体关闭。
- **预写采样缓冲**：轮廓格的采样 RGB 改写为描边色 RGB（在副本上，绝不改调用方输入），
  使最近邻精确映射、k-means 自然形成描边簇、edgeStrength 在轮廓处升高（后续 refine 自动保护）。

### 2. 内部边界锐化（Boundary Snap，量化后）

对每个非空、非锁定、非轮廓格：
- 找 4 邻域中与该格**采样色差最大**的邻居 n，若最大 ΔE ≥ `snapDelta`（说明该格骑在强边界上）；
- 候选 = 邻居的映射色；仅当候选比当前色**更暗**，且 ΔE(采样, 候选) ≤ ΔE(采样, 当前) + `snapTolerance`
  （保真度让步在容差内）→ 归入深色侧。

单趟扫描（row-major，确定性），不做迭代防止连锁变暗。效果：交界带收敛到深色侧，边界干净。

### 3. 特征保护锁（Feature Lock，量化后、flatten 前）

对最近邻结果做同色 4 连通分量标注：
- 分量尺寸 ≤ `featureMaxSize`（如 3-4 格）且与环绕主色 ΔE ≥ `featureContrast`（如 25）→ 全分量锁定；
- 锁定格：flatten 不改写（但保留投票权）、refine 不修复、snap 不参与。
- 有锁兜底后，主体区域的平整化阈值可以更果断（anime 多数投票阈值 ×1.4 → ×1.6）。

### 4. 模式策略（ModeProfile.outline，可选字段）

| 模式 | rim 描边 | snapDelta / tol | featureMax / contrast | 说明 |
| --- | --- | --- | --- | --- |
| anime | 开 | 26 / 6 | 4 / 25 | 描边+锐化全开，市面动漫风基准 |
| photo | 开 | 30 / 5 | 3 / 28 | 画像黑边（用户诉求主场景），特征门槛更高 |
| logo | 开 | 22 / 4 | 6 / 18 | 图标小细节多，锁更宽松 |
| landscape | 关 | 34 / 4 | 2 / 30 | 风景无主体轮廓概念，只做轻锐化 |

## 管线时序（升级后）

```
sample → [描边预写+色位预留] → k-means 选色 → 最近邻 → [特征锁计算]
       → flatten(锁) → [边界锐化(跳过锁/轮廓)] → refine(锁) → 诊断
```

## 验证

- 单测：rim 检测形状、锚色三分支、预留不变量（长度==maxColors、含锚色）、锐化单调性、锁保护、
  幂等性（flatten→snap→refine 二次调用不变）。
- quality-run 新增指标：`outlineCoverage`（轮廓格映射为深色的比例）、`transitionsPer100`
  （百格色块过渡数，越低越干净）；21 张测试图前后对比 + 图纸目检。
- 回归红线：meanΔE 不恶化超过 +1.0（描边是有意改色，允许轮廓格 ΔE 上升）。

# 增补 · S11.1 描边中和（2026-10-25）

> 用户反馈：初版描边「太刻意」。本节诊断刻意感来源并给出中和方案。

## 刻意感来源诊断

1. **全局统一锚色**：蓝主体、红主体、肤色主体都贴同一根近黑线——描边读作「外贴物」
   而非主体自己的暗部。市面图纸的边线颜色是随主体局部色调走的。
2. **100% 闭环覆盖**：黑发、深衣等本来就是深色的边界被再描一圈纯黑，形成「双线」；
   一根粗细均匀的完整闭环本身就有机械感。
3. **描边色与主体无关联**：中和的目标是让轮廓线读起来像「主体的轮廓阴影」。

## 中和策略（三项）

### 1. 调和描边色（核心）——边线 = 主体局部色的暗化版

每个轮廓格的改写色不再统一取全局锚色，而是：

```
内侧参考色 = 该格 4 邻中非空格采样色的 Lab 均值（通常即紧邻的主体色）
调和目标   = Lab( L ← max(10, L内侧 × 0.3)，a/b 保持 )
映射       = 全色卡深色族（L* < 45）中最近的【真实色号】
兜底       = 映射色与全局锚色 ΔE > 40 时退回全局锚色（防跑出怪色）
```

效果：肤色段的边线是深肤棕、红衣段是深红棕、蓝裤段是深藏蓝——描边「长在」主体上。
深色族可能收敛出 1–2 个色号（黑 + 深棕），与市面图纸常备 H7 + M12/M15 的形态一致。

### 2. 深色豁免断线——不重复加深

内侧参考色 L* < skipL 的轮廓段**不描**（黑发边保持黑发的颜色）。
描边从「机械闭环」变成「随主体明暗起伏的轮廓阴影」，自然断线。

### 3. 强度参数化 rimStrength（0–1）——用户可拧

```
skipL = 30 + (1 − rimStrength) × 65
```

- rimStrength = 1 → skipL 30：几乎全描（接近初版）
- rimStrength = 0.75 → skipL ≈ 46：深色段豁免（**默认中和档**）
- rimStrength = 0 → skipL 95：几乎不描（连浅色主体都豁免）

- rimStrength = 1 → skipL 30：几乎全描（接近初版）
- rimStrength = 0.75 → skipL 37.5：深色段豁免（**默认中和档**）
- rimStrength = 0 → skipL 60：几乎不描

profile 默认：photo 0.75 / anime 0.8 / logo 0.9 / landscape（rim 关闭）。
UI 在「高级选项」暴露「描边强度」滑杆（仅描边模式显示），`outlineStrength` 作为
`GenerateInput` 可选字段覆盖 profile 默认（空 = 跟随模式）。

## 色位预留的调整

全局锚色仍预留 1 位（兜底与跳色保障）；调和色经 k-means 自然入色板
（轮廓格占非空格 8–15%，形成稳定深色簇）。全部轮廓格被豁免时不预留。

## 验证口径更新

- `rimDarkRatio` 改为**浅色段描边覆盖率**（只统计内侧 L ≥ skipL 的轮廓格），目标 ≥ 90%；
- 新增 `rimSkipRatio`（自然断线比例，预期 15–40%，过小说明中和不足、过大说明强度偏低）；
- 其余指标（内部 ΔE / 碎片 / 孤立豆 / 过渡率）与 S11 基线直接对比，要求不回退。
