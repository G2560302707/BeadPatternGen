审计日期：2026-10-24  
范围：本阶段实际引入的数据集，以及规格第 3 章**计划**在后续阶段加入的第三方包。S01 **没有**执行 `pnpm add`，下表版本栏为「计划锁定时机」，不是已安装版本。

判定用语：

- **允许商业分发**：许可证是否允许闭源/商业产品中使用该组件（仍须遵守署名等条件）。
- **传染性**：是否为 GPL / AGPL 一类、要求衍生作品同许可证开源。
- **NOTICE**：分发时是否必须保留版权声明或 NOTICE 文件。

## 3. 商标与数据风险（非版权许可证，但必须写清）

- **Artkal / Perler / Hama / MARD** 等是各厂商商标。MIT 色卡数据**不等于**官方授权使用商标做官方产品。UI 必须标明「非官方色值 / 社区测量」。
- HEX 来自社区贡献者（CSV 第 6 列），不是 Artkal 公开发布的机器可读色度标准。购买豆子必须以**色号**为准。

## 4. 总判断

当前引入的唯一第三方运行时数据许可干净（MIT、需署名、非传染）。计划技术栈以 MIT / Apache-2.0 为主，**未计划 GPL/AGPL 依赖**。S02 安装后应把 lockfile 实际许可证回填本表版本列。
